!1 Mission Execution Tests

These tests validate the mission execution endpoints of the UAV API.

!2 Test 1: List Missions (Initially Empty or Existing)

|script|mission fixture          |
|list missions                   |
|check|status code        |200  |

!2 Test 2: Create MoveTo Mission

|script|mission fixture                     |
|create move to mission;   |100|200|50      |
|check|status code                   |200   |
|check|response contains|id                |true|
|check|response contains|mission_type      |true|
|check|response contains|status            |true|
|check|number of assigned drones     |3    |

!2 Test 3: Get Mission Details

|script|mission fixture                     |

|check|status code                   |200   |
|$missionId=|mission id                    |
|get mission detail        |$missionId      |
|check|status code                   |200   |
|check|response contains|mission_type      |true|
|check|response contains|status            |true|

!2 Test 4: Get Mission Status

|script|mission fixture                     |

|check|response contains|mission_id        |true|
|check|response contains|status            |true|
