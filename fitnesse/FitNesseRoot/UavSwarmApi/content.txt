!1 UAV Swarm REST API Test Suite

This test suite validates the REST API for the UAV Swarm Management system.

!2 Test Organization

!3 Test Suites
 * '''[[Swarm Tests][.UavSwarmApi.SwarmTests]]''' - Tests for swarm management endpoints
 * '''[[Drone Tests][.UavSwarmApi.DroneTests]]''' - Tests for individual drone operations
 * '''[[Formation Tests][.UavSwarmApi.FormationTests]]''' - Tests for formation control
 * '''[[Mission Tests][.UavSwarmApi.MissionTests]]''' - Tests for mission execution

!2 Prerequisites

Before running these tests:
 1. Build the Rust API server: {{{cargo build --release}}}
 2. Start the API server: {{{cargo run -- serve --port 8080}}}
 3. Build the Java fixtures: {{{cd fitnesse/fixtures && mvn clean package}}}
 4. Start FitNesse: {{{./run-fitnesse.sh}}}

!2 API Base URL

Tests connect to: '''http://localhost:8080'''

To override, set system property: {{{-Dapi.base.url=http://your-server:port}}}
